# Verified MSP430 diagnostic image

This extends the reviewed native/SSH image without changing the published
benchmark image or canonical runner. See the
[results and remaining failures](../../../docs/deepswe-pwntools-msp430-2026-10-07.md).

The follow-on [RISC-V/patchelf image](RISCV.md) reruns that same public Docker
schedule with two additional verified packages. It does not replace the
MSP430-only results recorded here.

From the repository root, check the parent identity before building:

```powershell
$pwntoolsNativeParent = 'sha256:3edc96947982c955bf4e7161e8f3dbadcf157d1943b27ecab1716ab9ff7560e4'
$actual = docker image inspect agentless-ml/pwntools-native:2026-10-07 --format '{{.Id}}'
if ($LASTEXITCODE -ne 0 -or $actual -ne $pwntoolsNativeParent) { throw 'Native parent differs from the reviewed image' }
docker build -f experiments/deepswe/pwntools/Dockerfile.msp430 `
  -t agentless-ml/pwntools-msp430:2026-10-07 experiments/deepswe/pwntools
```

The recipe checks the publisher's archive checksum before extracting or
building it. The source manifest records configure flags and provenance.
The final image contains executable hashes under
`/opt/pwntools-msp430/binary-sha256.txt`. A rebuild can produce a new image
identity: record and review that identity rather than assuming the tag proves
equivalence. The native parent's APT inputs are not a version lock.

Verify the installed binaries and the complete assembly/link/disassembly path:

```powershell
$env:AGENTLESS_PWNTOOLS_MSP430_IMAGE = 'agentless-ml/pwntools-msp430:2026-10-07'
$env:AGENTLESS_PWNTOOLS_MSP430_ARTIFACTS = 'C:/Users/GIGABYTE/Desktop/Agentless-ML/output/deepswe-survey/pwntools-msp430-preflight-local'
.\.venv\Scripts\python.exe -m pytest tests/test_pwntools_msp430.py -q
Remove-Item Env:AGENTLESS_PWNTOOLS_MSP430_IMAGE
Remove-Item Env:AGENTLESS_PWNTOOLS_MSP430_ARTIFACTS
```

Selected pages, with no exclusions:

```powershell
.\.venv\Scripts\python.exe tools/run_pwntools_native_tests.py `
  --image agentless-ml/pwntools-msp430:2026-10-07 `
  --artifacts ../output/deepswe-survey/pwntools-msp430-selected-local
```

Broader documented Docker schedule:

```powershell
.\.venv\Scripts\python.exe tools/run_pwntools_native_tests.py `
  --image agentless-ml/pwntools-msp430:2026-10-07 `
  --public-docker-schedule --timeout-seconds 1800 `
  --artifacts ../output/deepswe-survey/pwntools-msp430-public-docker-local
```

This last command deliberately excludes only the three pages excluded by the
public Docker script: GDB, ADB and protocols. It does not enable upstream's
privileged/host-network settings. Do not combine this option with `--full`;
the latter requests the unchanged suite and is a different diagnostic.
Artifacts accumulate in unique directories and failures remain failures.
